python run_lab.py verify

What you should notice

A useful negative control

The default generator deliberately makes one label's alpha component stronger. The near-perfect classifier score is not a discovery about a brain.

python run_lab.py demo --null-effect \
  --out results/my_null

Removing the effect should make the labels difficult to predict. Included example: 100% → about 54% balanced accuracy, with a 50% baseline.

A channel measures a difference

Vchannel = Vpositive − Vnegative

A change may come from neural activity, an eye movement, muscle tension or an electrical artifact. A waveform alone does not identify its source.

Two different references

The electrode reference is the comparison potential for a channel. The ADC voltage reference sets the conversion scale. Do not connect them interchangeably.

Bias is an active circuit

A bias electrode affects common-mode voltage through a reviewed circuit. It is not household ground. The starter firmware leaves the bias driver off and provides no body-connected mode.

A model answers a limited question

Python solves the illustrative passive network here. Separate Python code models digitization and synthetic signals. The exported ngspice circuits have not executed in this environment. None of these is a safety or brain model.

Functional architecture only. Power, input protection, physical connectors and electrode routing are intentionally not invented. Read model scope.

Change one thing and predict the result

Will a small signal fit on a large offset?

Educational example: nominal 4.5-V reference and 0/5-V analog rails. The differential offset is treated as the input value; allow extra margin for the waveform itself. These are calculator assumptions, not power-pin instructions.

Try 300 mV at gain 24. Then lower the gain. Finally move common mode toward a rail: a small differential input can still violate amplifier headroom.
